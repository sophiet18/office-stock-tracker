# Office Stock Tracker

A Python tool for tracking office supplies, built one stage at a time as I learn Python.

## Status

Planning. No application code yet. Each stage below is marked complete only when it works and has been checked.

## Why this project

Office supplies like paper, toner and pens run out at awkward moments, and reordering depends on someone noticing. This project starts as a small stock checker and grows as my Python skills do. It began as a freeCodeCamp kitchen-stock exercise (see my [freecodecamp-learning](https://github.com/sophiet18/freecodecamp-learning) repository), and I changed the setting to an office so the result is more practical.

## Stages

| Stage | New skill | What the tool gains | Status |
|---:|---|---|---|
| 1 | Functions and variables | Check stock, use an item | Planned |
| 2 | Dictionaries and lists | Track any item, with a reorder level | Planned |
| 3 | Conditionals and loops | List every item below its reorder level | Planned |
| 4 | Files (such as JSON) | Save stock between runs | Planned |
| 5 | Classes | Items and requests as objects | Planned |
| 6 | Tests | Prove the logic works | Planned |
| 7 | Data analysis | Usage trends and what runs out fastest | Planned |
| 8 | AI | Turn a pasted request message into a stock update | Planned |
| 9 | Sharing | A shared request list for a team | Planned |
